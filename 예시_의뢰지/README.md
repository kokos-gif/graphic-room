# 예시 의뢰지 8장

앱에 그대로 올려 볼 수 있는 손글씨 의뢰지 사진입니다. 여덟 장 모두 끝까지 완성되는 것을 확인한 것만 골랐습니다(2026-11-25 오전의 코드로 다시 돌려 확인).
프로그램명 · 사람 이름 · 연락처는 모두 가상입니다. 사진의 기기 · 촬영 시각 정보는 지웠고 그림은 올렸던 원본과 같습니다.

## 쓰는 법

1. 앱을 켜고(`python -m mapcg serve`) 입력 칸의 첨부 버튼으로 사진 한 장을 붙입니다. 글은 적지 않아도 됩니다.
2. 보내면 메인 에이전트가 의뢰를 읽고 확인 카드를 띄웁니다. 카드 내용을 보고 만들기를 누릅니다.
3. 미리보기를 확인한 뒤 영상으로 내보냅니다.

## 여덟 장

| 파일 | 만들어지는 것 | 알아 둘 것 |
|---|---|---|
| `1_지도2컷_서울역-DDP.jpg` | 지도 CG 2컷(서울역 → DDP), 14초 | 소개 영상의 첫 번째 의뢰와 같은 의뢰지입니다 |
| `2_네비_여의도공원-노량진역.jpg` | 휴대폰 길안내 화면 모양의 이동 영상 | 확인 카드에서 출발 · 도착 지명을 직접 적어 줘야 할 때가 있습니다 |
| `3_순위판_미션점수.jpg` | 순위판(1차 미션 출연자 점수) | 확인이 필요한 칸이 카드에 표시됩니다. 제안된 값 그대로 만들 수 있습니다 |
| `4_카드퀴즈.jpg` | 카드 퀴즈(카드 7장 뒤집기, 정답 공개) | |
| `5_맞춤그래픽_구매리스트.jpg` | 맞춤 그래픽: 메인 에이전트가 서브에이전트를 즉석에서 만들어 제작(화살표가 차례로 등장) | 맡을 서브에이전트가 없는 의뢰의 예입니다. 시안 제작과 검수에 1~2분이 걸립니다. 검수 결과가 '합격'이 아니라 '미해결 제출'로 나올 때가 있습니다(앞 화살표가 남은 채 다음 화살표가 쌓이는 연출을 검수가 지적한 경우). 남은 문제는 결과 카드에 적힙니다 |
| `6_건물안이동.jpg` | 정보판: 건물 단면에서 지하 주차장 → 계단 → 엘리베이터 → 목표 층으로 이동, 8초 | 의뢰지에 적힌 작업 메모('엘베 이동 모션')가 단계의 말로 읽혀 화면 꼬리표에 들어갈 때가 있습니다. 확인 카드의 '그 단계의 말' 칸에서 지우고 만들면 됩니다 |
| `7_지도_강변북로-중대병원.jpg` | 지도 CG(강변북로 → 한강대교 → 중대병원), 10초 | 지도에 없는 이름 '중대병원'을 Liner Search 로 '중앙대학교병원'으로 확인하고, 맞는지 봐 달라고 알립니다. 출발지가 도로 이름('강변북로')뿐이라 도로 위 한 지점이 출발점으로 잡히고, 경로가 처음에 반대쪽으로 갔다가 돌아 나올 때가 있습니다 |
| `8_VS점수.jpg` | VS 대결판(2차 카드 게임 점수, 5경기), 8초 | 제목 옆 카드 · 게임 말 장식은 준비된 화면 구성으로 만들 수 없다고 메인 에이전트가 따로 보고합니다 |

## 한계

- 손글씨 판독은 같은 사진도 돌릴 때마다 조금씩 다르게 읽힙니다. 그래서 만들기 전에 확인 카드에서 사람이 확정합니다.
- 여기 없는 의뢰 가운데에는 끝까지 가지 못한 것도 있습니다: 3컷 네비와 컷 나눔을 함께 요구한 의뢰, 번호로만 적힌 출발지, 도착지를 적지 않은 4컷 동선, 팀별 세로 막대그래프(세로 막대 구성이 없어 팀마다 가로 막대 한 장씩 네 장으로 나옵니다), 공원 안 지점 이름으로만 적은 글 의뢰(지도에서 찾지 못함).
