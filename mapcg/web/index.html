    방송그래픽 의뢰 자동화
    메인 에이전트

    의뢰를 아래 칸에 적거나, 의뢰서 사진(JPG·PDF)이나 통화 녹음(MP3·M4A·WAV)을 이 창에 끌어다 놓으면 됩니다. 지도, 순위판, 정보판, 카드 퀴즈는 전문 담당이 만들고, 처음 보는 형식의 의뢰는 메인 에이전트가 담당을 새로 만들어 맡깁니다.

    예시 1 · 지도
    지도 담당이 맡습니다
    〈오늘도 출발〉 김가상 조연출입니다(010-0000-0000). 출연진 4명이 버스를 타고 노들섬에서 여의도로 이동하는 장면 지도 부탁드립니다. 네비게이션처럼 남은 거리가 보이는 지도로, 960*540 전체화면, 총 8초입니다.
    예시 2 · 게임 코너
    설명판 담당과 임시 담당이 나눠 맡습니다
    감독님, 미션추격자들(가칭) 3회 새 게임 코너 CG 부탁드립니다! 게임 이름은 '눈치 숫자'예요. 게임 방법 설명판 하나 주세요. 1. 진행자가 '시작'을 외치면 1부터 차례로 숫자를 외친다 2. 두 명이 같은 숫자를 동시에 외치면 둘 다 탈락 3. 마지막 숫자를 외친 사람도 탈락 4. 끝까지 남은 두 명이 결승 진출 그리고 라운드 시작할 때마다 화면 가운데 큰 글자로 5·4·3·2·1 카운트다운 넣어 주시고(3초, 빠르게, 촬영본 위에 얹게 바탕 투명), 1라운드 끝나면 하단 자막으로 '1라운드 탈락: 철수 · 영희' 깔아 주세요. 설명판은 8초, 1920×1080 30fps 요.
    예시 3 · 처음 보는 그래픽
    메인 에이전트가 임시 담당을 꾸립니다
    세 사람 말이 어디서 엇갈리는지 방송에 한 장으로 보여 주세요. 가람 "8시 10분에는 나래랑 대기실에 있었어요." 나래 "8시 10분에 저는 소품실에서 열쇠를 챙겼어요." 다온 "8시 15분에 복도에서 나래를 만났어요."
