# 지도 형식 레퍼런스를 넣는 자리

형식마다 폴더 하나(`01_이름\` ~ `06_이름\`)를 만들어 참고 그림이나 영상을 넣는다.
넣은 뒤 분석해서 **코드로 그릴 수 있는 것**과 **그림이 필요한 것**으로 나눈다.

| 번호 | 형식 | 코드 / 그림 | 상태 |
|---|---|---|---|
| 01 | 경로 이동 | 코드 | 1차 구현됨(`route_move`) — 레퍼런스에 맞춘 모양 조정은 아직 |
| 02 | | | |
| 03 | | | |
| 04 | | | |
| 05 | | | |
| 06 | | | |

방송에 나간 실제 화면을 넣을 때는 프로그램 로고·출연자 얼굴이 제출물에 섞이지 않게 한다(이 폴더를 제출물에서 뺄지 그때 정한다).
