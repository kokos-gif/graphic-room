# Graphic Room — 방송그래픽 의뢰를 읽고 영상 그래픽을 만드는 에이전트(지도 · 순위판 · 정보판 · 카드 퀴즈 · 맞춤 그래픽)

> 앱 이름은 **Graphic Room**(화면 이름 "방송그래픽 의뢰방")이다. 코드 묶음 이름과 실행 명령(`python -m mapcg serve`)의 `mapcg` 는 지도만 만들던 때의 예전 이름을 그대로 쓴다.

방송그래픽 업무 가운데 **지도(컷 나눔 포함) · 순위판 · 정보판(VS 대결판 · 설명판 · 건물 안 이동) · 카드 퀴즈**는 정해 둔 틀로 만들고,
틀이 없는 처음 보는 의뢰(진술 대조판 · 영수증 · 오프닝 · 덮는 전환 …)는 **맞춤 그래픽** — 메인 에이전트가 제작 지시서를 쓰고 이 의뢰만을 위한 임시 담당(서브 에이전트)을 꾸리면,
담당이 시안을 그리고 Liner 그림 읽기로 검수받아 스스로 고치고, 메인이 다시 시키거나 납품한다(아래 '맞춤 그래픽' 절). 의뢰는 글 · 의뢰서(JPG · PDF) · 음성(MP3 · M4A · WAV, 받아써서 읽는다)으로 받는다. 지도는 출발·도착, 길이, 화면 배치, 이동 아이콘과 얼굴을 받아 공개 지도 데이터로 실제 도로를 따라가는 영상을 만든다. 지도 · 판 · 글자 · 움직임은 코드로 그린다. 순위판에는 미리 만든 소품 아이콘을 쓰고, 카드 퀴즈의 뒷면과 그림 단서는 Liner가 생성한다.

라이너 .EXE-THON 2026 출품작이다. 종류별 쓰는 법은 아래 절들에 있다.

**말 맞추기** — 소개 영상 · 기획서와 이 문서 · 앱 화면은 같은 것을 다른 말로 부른다: 메인 에이전트 = **CG Director**(접수)와 맞춤 그래픽의 메인 · 기존 서브에이전트 = **전문 담당**(지도 · 순위판 · 정보판 · 카드 퀴즈) · 즉석에서 만든 서브에이전트 = **임시 담당** · 화면 구성 = **틀 · 배치** · 디렉터 = 앱을 쓰는 사람.

## Liner API 를 사용한 기능

**Liner 키(`LINER_API_KEY`) 하나로 전부 돈다.** 호출은 의뢰 번호로 묶어 `data/liner_calls.jsonl` 에 남고, 카드마다 그 의뢰가 쓴 Liner 가 한 줄로 보인다
(`⚡ Liner 3번 · 9초 · 약 $0.012 — 읽기 gpt-6-sol · 감사 claude-sonnet-5.5` — 라우터가 일마다 실제로 고른 모델 · 비용은 문서 단가로 어림).

| 기능 | Liner API | 쓰는 것 | 코드 | 언제 |
|---|---|---|---|---|
| **의뢰서 그림 받아쓰기** — 다른 읽기보다 먼저 손글씨 · 스케치의 글씨를 틀 없이 그대로 받아 적고 요약한다. 받아 적은 글은 CG Director · 의뢰 읽기에 그림과 함께 넘기고, 판독 감사에는 넘기지 않는다(감사는 그림을 따로 읽는다) | **Model** | `liner-gpt-router` · `quality` · 그림 입력 · 평범한 글 출력(JSON 틀 없음). 받아 적은 글은 진행 표시에 보인다 | `transcribe.py` | 그림 · PDF 를 붙였을 때 1번(앱으로 켰을 때, `MAPCG_SHEET=off` 면 끈다) |
| **CG Director — 접수**: 의뢰를 맨 먼저 읽고 [실무 확인 목록](노하우_실무확인목록.md)을 적용해 일을 나눈다(전문 담당 하나 + 틀 밖은 임시 담당) | **Model 도구 호출(`tools`)** + **Search** | `liner-claude-router` — `search_web`(`/tools/search/web`, 헷갈리는 장소 · 이름) · `check_fact`(`/agents/quick-answer`, 화면 속 공개 사실) · `assign` · `custom` · `ask` · `finish`. 접수 판단 카드에 적용한 번호 · 의뢰 원문 근거 · 검색 출처 | `director.py` · `knowhow.json` | 의뢰마다 맨 먼저(앱으로 켰을 때, `MAPCG_FRONT=off` 면 끈다) |
| 의뢰 읽기 — 글 · 의뢰서 그림 · PDF(앞 3쪽을 그림으로) | **Model** | `liner-gpt-router`(기본, `LINER_MODEL`) · 그림 입력 · JSON 스키마 출력 | `intake.py` · `board.py` · `plan.py` · `quiz.py` | 의뢰마다 1번 |
| 판독 감사 — 읽은 값을 원문과 다시 대조 | **Model** | 읽은 쪽과 다른 라우터(`liner-claude-router` 등) | `audit.py` | 지도 의뢰마다 1번 |
| 음성 의뢰 받아쓰기 | Model(받아쓰기) | `/audio/transcriptions` | `voice.py` | 음성을 붙였을 때 |
| 지명을 지도에서 찾을 이름으로 | **Model** | 적힌 지명 → 정식 이름 · 종류 | `intake.official_names` | 컷 나눔 · 각자 이동 |
| 지도에 없는 지명 확인 | **Search** + Model | `/tools/search/web` 결과를 근거로 정식 이름 · 지도 후보를 고르고 출처 주소를 남김(근거 없는 답은 버림) | `intake.searched_name` · `intake.picked_place` | 지명 서버가 못 찾았을 때 |
| 수정 지시 — '도착지만 바꿔 줘' | **Model** | 바뀔 항목만 뽑아 확인 카드에 표시 | `revise.py` | 결과 카드에서 고칠 점을 보낼 때 |
| 맞춤 그래픽 메인 에이전트 | **Model 도구 호출(`tools`)** | `liner-claude-router` — `research` · `write_brief` · `spawn_worker` · `report_unable` · `redo_worker` · `deliver` | `scene.py` | 틀 없는 의뢰 · 남은 요청 |
| **자료 찾기** — 의뢰 글에 없는 공개 사실(기록 · 순위 · 수치) | **Search(에이전트)** | `/agents/quick-answer` — 출처(사이트 · 날짜 · 원문)가 붙은 답. 사실의 근거는 의뢰 글이나 이 출처 원문에 있어야 받는다(지어내기 금지) · 지시서 카드와 화면 아래 주석에 출처 | `liner.research` · `scene.plan_request` | 메인이 research 를 부를 때(의뢰마다 2번까지) |
| 맞춤 그래픽 담당(서브 에이전트) | **Model 도구 호출(`tools`)** | `liner-claude-router` — `draw_draft` · `request_review` · `submit` · `give_up`(순서는 담당이 정한다) | `scene.py` | 지시서 카드에서 만들 때 |
| 시안 검수 — 확인할 점마다 예/아니오 + 근거 | **Model** 그림 읽기 | `liner-gpt-router` · JSON 스키마 | `scene.judge` | 담당이 검수를 부를 때 |
| 완성 화면 검수 — 영상의 글자를 읽어 의뢰와 대조 | **Model** 그림 읽기 | `liner-gpt-router` | `proof.py` | 영상을 내보낸 뒤 |
| 카드 퀴즈 그림 · 이동 아이콘 그림 | 이미지 생성 | `/images/generations` | `quiz_build.py` · `icons.py` | 새 그림이 필요할 때(한 번 그린 것은 보관해 다시 씀) |
| **맞춤 그래픽의 항목 그림** — 줄 목록 · 나란히 배치에서 아이콘이 없는 항목 이름(곰인형 · 기차 · 만원 …)에 맞는 작은 그림을 붙인다. 글 모델이 낱말마다 그릴 물건을 고르고(사람 · 상표 · 글자는 고르지 않는다), 그림 모델이 우리 아이콘 시트를 보고 같은 화풍으로 그린다 | Model · 이미지 생성 | 낱말 고르기 1번 + `/images/generations`(새 물건마다 1번, 장당 약 0.014달러 · 10초쯤). 75초 안에 안 오면 그 시안은 그림 없이 그린다 | `scene.py`(`attach_pictures`) · `icons.py` | 맞춤 그래픽을 만들 때(앱으로 켰을 때, `MAPCG_SCENE_PICS=off` 면 끈다. 한 번 그린 것은 보관해 다시 씀) |

그림 · 글자 · 움직임은 모델이 아니라 우리 그리기 코드가 그린다 — 모델은 읽고 · 설계하고 · 검수한다(모델이 만든 코드는 실행하지 않는다).

**구조 한눈에**: 의뢰 → **CG Director**(실무 확인 목록 적용 · Liner Search 로 확인 · 일 나누기 → 접수 판단 카드)
→ 전문 담당(지도 · 순위판 · 정보판 · 카드 퀴즈 — 검증된 틀로 빠르고 회차 내내 같은 디자인) · 임시 담당(틀 밖의 부분 — 메인 에이전트가 그 의뢰만의 담당을 꾸려 시안 → Liner 검수 → 스스로 고침)
→ 사람이 확인 카드에서 확인 → 영상 → 완성 화면 검수. CG Director 를 부르지 못하면 예전 순서(순위판 판별 → 지도 읽기)로 읽는다.
실무 확인 목록(K01~K24)은 방송 CG 감독이 의뢰마다 돌리던 확인 순서이고, 규칙마다 그것을 지키는 코드 자리를 적었다 — 그 자리가 실제로 있는지는 시험이 확인한다(`tests/test_director.py`, 동작까지 보는 시험은 각 기능의 시험이다).
영상 · README 예시가 지나는 서울 세 곳의 지도 자료(OpenStreetMap, ODbL)는 `mapcg/packs/osm` 에 같이 실어, 공개 지도 서버가 붐벼도 골목길까지 바로 그린다(`tools/osm_demo_pack.py`).

**라우팅 — 일마다 라우터 · 전략을 한 표로**(`liner.ROUTES`). 라우터는 그 회사 모델 가운데 어려운 요청만 비싼 모델로 보내고, 전략(cost · balanced · quality)은 우선순위만 준다.

| 일 | 라우터 · 전략 | 까닭 |
|---|---|---|
| 의뢰 읽기 · 지명 · 그림 주제 · 수정 지시 | gpt · balanced | 그림이 든 요청은 어차피 그림 읽는 모델로 고정. 지명은 cost 를 실측했지만(11-22) gpt-6.1-terra 가 4.4초로 더 늦고 경기장 이름이 지도 이름에서 멀어져 balanced |
| 판독 감사 | claude · balanced | **읽은 쪽(gpt)과 다른 회사**가 원문과 다시 대조 |
| 맞춤 그래픽 메인 · 담당(도구 호출) | claude · quality | 계획 · 도구 호출 — 라우터가 어려운 차례만 opus 로(실측: sonnet 91 · opus 62번) |
| 시안 검수 · 완성 화면 검수 | gpt · quality | **그린 쪽(claude)과 다른 회사**가 그림을 읽고 판정 |

라우터가 실패하면(보내지 못함 · 5xx) **다른 회사 라우터로 한 번 더** 보낸다 — 검사 쪽(감사 · 시안 검수)은 만든 쪽과 같은 회사로 넘어가지 않게 세 번째 회사(gemini)로.
답을 기다리다 끊긴 것은 접수됐을 수 있어 다시 보내지 않는다.

## 실행

Python 3.11 이상 · `pip install -r requirements.txt`(Pillow · NumPy · SciPy — Pillow · NumPy 가 없으면 앱이 켜지지 않고, SciPy 가 없으면 출연진 시트에서 얼굴을 자르지 못한다).
`.env.example` 을 `.env` 로 복사해 `LINER_API_KEY` 를 넣는다(또는 환경 변수로).
미리보기 · 시안 찍기 · 영상 저장에는 **크롬(또는 엣지 · 크로미엄)** 이, 영상(MP4)에는 **ffmpeg** 가 있어야 한다.
바로 올려 볼 수 있는 손글씨 의뢰지 사진 8장은 [예시_의뢰지](예시_의뢰지/README.md)에 있다(2026-11-25 코드로 끝까지 완성되는 것을 확인한 것만).

### 처음 실행한다면 (3분)

1. `python -m mapcg serve` 로 켜고, 첫 화면의 **예시 1 · 지도** 를 입력 칸에 넣어 보낸다 → 확인 카드 → 만들기 → 영상 내보내기.
2. **예시 2 · 게임 코너** 를 보낸다 — 설명판은 기존 담당이, 카운트다운과 탈락 자막은 메인 에이전트가 즉석에서 만든 담당 둘이 만든다.
3. [예시_의뢰지](예시_의뢰지/README.md)의 손글씨 사진 한 장을 창에 끌어다 놓는다.

### 알려진 한계 — 지어내지 않고 멈춰서 알린다

방송에 나갈 그래픽이라, 확실하지 않은 것은 앱이 채워 넣지 않고 디렉터(앱을 쓰는 사람)에게 묻도록 만들었다.

| 이런 때 | 앱이 하는 일 | 디렉터가 할 일 |
|---|---|---|
| 지도(OpenStreetMap)에 없는 작은 장소 · 건물 | 띄어쓰기를 바꿔 다시 찾고, Liner Search 로 정식 이름 · 주소를 확인해 다시 찾는다. 그래도 없으면 멈추고 알린다 | 확인 카드의 📍 지점 지정으로 찍는다 |
| 준비된 화면 구성 11가지 밖의 모양 · 사진 합성 | 비슷하게 지어 그리지 않고 "새 도구 필요"로 보고한다 | 편집에서 처리한다(새 구성은 개발 단계의 연구실에서 만든다) |
| 손글씨가 흐리거나 두 가지로 읽힐 때 | 다른 모델이 의뢰서와 한 번 더 대조해 "확인할 곳"으로 표시한다 | 확인 카드에서 고친다 |
| 네비 화면과 컷 나눔을 함께 요구한 의뢰 | 만들기를 거절하고 바꿀 지도 모양을 알려 준다 | 지도 모양을 바꾼다 |
| 같은 의뢰도 결과가 조금씩 다르다 | Liner 모델 API 가 `temperature` · `seed` 를 반영하지 않는다 | 확인 카드에서 확정한 값으로 만든다 |

| OS | 크롬 | ffmpeg |
|---|---|---|
| Windows | 보통 깔려 있다 | `winget install Gyan.FFmpeg` |
| macOS | `/Applications` 의 Google Chrome 을 저절로 찾는다 | `brew install ffmpeg` |
| Linux | `google-chrome` · `chromium` | `sudo apt install ffmpeg` |

다른 자리에 깔았으면 `MAPCG_BROWSER` · `MAPCG_FFMPEG` 에 실행 파일 경로를 넣는다. 화면 글자는 같이 싣는 글꼴(프리텐다드)로 그려 OS 와 상관없이 같다.
macOS 에서 python.org 설치본을 쓰면 처음 한 번 `Install Certificates.command`(응용 프로그램의 Python 폴더)를 실행한다 — 하지 않으면 Liner · 지도 서버 호출이 인증서 오류(`CERTIFICATE_VERIFY_FAILED`)로 실패한다.

제출 묶음은 폴더를 통째로 압축하지 말고 `python tools/pack.py --test` 로 만든다 — 깃이 관리하는 파일만 묶고(`.env` · `output` · `data` · `시험결과` 는 들어가지 않는다), 묶음을 빈 폴더에 풀어 전체 시험까지 돌려 본다.

```
python -m unittest discover -s tests -t .
python -m mapcg serve
```

`serve` 는 의뢰 메신저를 브라우저로 연다(`http://127.0.0.1:8765/`, 내 컴퓨터에서만 열린다). 끄려면 실행 창에서 Ctrl+C.

1. 의뢰를 글로 적거나 의뢰서(JPG·PNG·PDF)를 끌어다 놓고 보낸다.
2. 앱이 읽은 내용이 **확인 카드**로 온다. 틀린 곳을 고치고, 못 찾은 칸을 채운다.
3. 지명은 이름만 두면 그 일대의 대표 지점을 쓴다. 정확한 지점이 필요하면 `지도에서 정확히 지정` 으로 지도를 눌러 정한다.
4. `지도 만들기` → 대화에 미리보기가 뜬다. 다른 배치로 다시 만들 수 있다.
5. `영상으로 내보내기` → MP4(와 선택하면 투명 배경 PNG 시퀀스)가 만들어지고 저장 위치가 나온다.

**카드 퀴즈**는 같은 의뢰 메신저에서 만든다. Liner 키를 설정하고 의뢰서를 첨부하면 앱이 카드 순서, 힌트, 정답과 영상 규격을 읽는다. 한 문제에 그림·글자·물음표 카드 2~9장을 쓸 수 있다. 정답은 마지막에 한 번 공개하거나, 중간에 1차 답을 먼저 공개할 수 있다. 의뢰서와 다른 내용은 함께 보낸 글에 적거나 확인 카드에서 고친다.

**카드 퀴즈 만들기**를 누르면 Liner가 공통 뒷면과 필요한 그림 단서를 준비한다. V5 미리보기에서 **영상으로 내보내기**를 누르면 MP4가 작업 폴더에 저장된다. 물음표 카드의 글자는 최종 답과 동시에 공개된다.

모든 종류의 확인 카드와 결과 카드(맞춤 그래픽 시안 포함)에서 **화풍**을 고를 수 있다. 새 의뢰는 방송 화풍 V5 로 시작한다(`request.HOUSE_STYLE`, 아래 '화풍' 절). 의뢰 JSON에는 `"art_style": "v4"` 처럼 넣거나 아래처럼 명령줄에서 고른다.

| 화풍(키) | 특징 |
|---|---|
| V1 · 물감과 붓펜 (`claude` — 화풍을 적지 않은 옛 봉투) | 종이 결, 물을 많이 탄 물감, 굵기가 변하는 붓펜 선 |
| V2 · 거친 마른붓 (`codex`) | 같은 화면에 붓과 색만 바꿔 끼운 것 |
| V3 · 붓터치 (`codex_v3`) | 화면 구성은 V1 그대로, 넓은 면만 결을 따라 놓은 붓 자국으로 채운다 |
| V4 · 예능 그래픽 (`v4`) | 일본 예능 그래픽의 통상 관행을 참고: 필터 없는 민색 면, 굵고 또렷한 외곽선, 여러 겹 테두리 제목, 따뜻한 원색 |
| V5 · 방송 화면(새 설계) (`v5`, 방송 화풍 — 새 의뢰의 기본) | 모든 종류. 정보 전달이 먼저: 굵은 프리텐다드 글자(가장 작은 글자가 화면 높이의 1/30 이상), 모든 글자는 안전 영역(프레임 가장자리에서 5% 안쪽) 안, 글자에 겹을 쌓지 않는다(제목은 짙은 판 하나에 흰 글자 한 겹). 색은 한 색조로 몰지 않고 여러 색 파스텔(분홍·살구·노랑·민트·청록·하늘·연보라)을 고루 쓰고, 묵직한 색은 두 가지(남보라 먹·짙은 보라)만. 지도는 여러 색이 번진 크림색 땅·민트 녹지·하늘색 강, 순위판은 크림색 바탕에 여러 색 물결과 종이 띠. 초반의 거친 손맛(떨리는 붓펜 선·물감 고임·종이 알갱이)은 그림에만 둔다. 검수판에 안전 영역 선과 자동 검사 결과(안전 영역·글자 크기·글꼴)가 같이 나온다 |

한 점에서 뻗는 방사 줄무늬(햇살 모양)는 어떤 화풍에서도 쓰지 않는다 — 욱일기를 떠올리게 하기 때문이다. 그리는 도구에서도 뺐다.

화면 틀은 화풍마다 따로 두지 않는다. 화풍은 화풍 파일 하나(`templates/style_v3.js` · `style_v4.js` · `codex_brush.js`)가 디자인 기준 묶음의 값과 붓의 성질(`brush.js` 의 `Brush.STYLE`)만 바꾸는 방식이다 — 화면을 고치면 모든 화풍에 같이 적용된다.

```powershell
python -m mapcg make examples/순위판_게임점수.json --art-style codex
python -m mapcg make examples/노들섬_여의도_네비.json --art-style claude
python -m mapcg make examples/노들섬_여의도_네비.json --art-style codex_v3
python -m mapcg make examples/노들섬_여의도_네비.json --art-style v4 --sheet
```

의뢰서를 읽는 쪽은 셋이고, 어느 쪽이 읽었는지는 화면에 표시된다(왼쪽 띠에 지금 쓸 수 있는 쪽과 1순위가 나온다).

| | 읽는 것 | 조건 |
|---|---|---|
| Liner 모델 | 글 + 의뢰서 그림(PDF 는 앞 3쪽을 그림으로 바꿔 보냄) | `.env` 에 `LINER_API_KEY` (`.env.example` 을 복사). 넣은 뒤 다시 실행 |
| Claude Opus(노력 중간) | 글 + 의뢰서 그림 | 이 컴퓨터에 `claude` 명령줄 도구가 있고 로그인돼 있을 것(`claude auth login`). API 키는 필요 없다 |
| 간이 해석 | 글만, 정해진 말투만("홍대에서 여의도로", "8초", "좌하단") | 위 둘이 없거나 호출이 실패했을 때 |

읽는 순서는 지금 단순하다: Liner 키가 있으면 Liner → 다음 Claude → 다 안 되면 간이 해석(`mapcg/intake.py` 의 `route`).
`.env` 에 `MAPCG_READER=liner` · `claude` · `simple` 을 적으면 한쪽만 쓴다.
Claude 는 임시로 붙여 둔 보조다. **Liner 키 하나만 있어도 전부 돈다** — Claude 가 없으면 건너뛸 뿐이다.

### 판독 감사

읽기와 확인 카드 사이에 감사를 한 번 끼운다(`mapcg/audit.py`). 읽은 값을 **읽은 모델과 다른 모델**이 의뢰서 원문과 항목별로 다시 대조한다.

| 판정 | 뜻 | 카드 표시 |
|---|---|---|
| 근거 있음 | 읽은 값이 의뢰서와 맞다 | 표시 없음(감사 내역에만) |
| 의뢰서와 다름 | 의뢰서에 적힌 값이 읽은 값과 다르다 | 붉게 — 의뢰서의 값과 구절을 같이 보여 준다 |
| 의뢰서에 없음 | 읽은 값이 의뢰서 어디에도 없다(짐작한 값) | 붉게 |
| 의뢰서에 있는데 못 읽음 | 읽는 쪽이 놓쳤다 | 붉게 |
| 확인 못 함 | 감사가 항목을 빠뜨렸거나, 든 근거 구절이 보낸 글에 없다 | 내역에 표시 |

- 감사는 **고치지 않는다**. 어긋난 곳을 표시할 뿐이고, 고치고 만들지는 사람이 정한다.
- 감사 모델: Liner 키가 있으면 읽은 모델과 계열이 다른 Liner 모델(기본 읽기 `liner-gpt-router` → 감사 `liner-claude-router`). 키가 없으면 Claude 명령줄 도구. 같은 모델밖에 없으면 카드에 "독립성이 낮다"고 적는다.
- 감사 모델도 틀릴 수 있어서, 감사가 든 근거 구절이 보낸 글에 실제로 있는지는 코드로 다시 본다(글만 온 의뢰일 때. 의뢰서 그림에서 나온 구절은 코드로 확인하지 못한다).
- 쓸 모델이 없거나 호출이 실패하면 카드는 그대로 나오고 "감사 안 함/실패"가 적힌다. 항목을 하나도 가리지 못한 감사도 실패로 친다.
- 계열로 따진다: Claude 도구가 읽은 의뢰는 Liner 의 Claude 계열이 아니라 다른 계열(`liner-gemini-router`)이 감사한다.
- 감사는 확인 카드를 붙잡고 있으므로 읽기보다 짧게 기다린다(Liner 60초·재시도 1회, Claude 도구 2분). 읽을 때 방금 호출이 실패한 쪽은 다시 부르지 않는다.
- `.env`: `MAPCG_AUDIT=off` 로 끈다(비워 두면 켜져 있다). `LINER_AUDIT_MODEL` 로 감사 모델을 정한다.

메신저 없이 의뢰 봉투(JSON)로 바로 만들 수도 있다.

```
python -m mapcg make examples\홍대_여의도.json --open
python -m mapcg make examples\노들섬_여의도_네비.json --open
python -m mapcg make examples\노들섬_여의도_네비.json --sheet     # 영상 대신 검수판(네 시각을 한 장에 모은 그림)
```

`output\<날짜-시각>_<출발><도착>_<배치>\` 에 결과가 생긴다.

| 파일 | 내용 |
|---|---|
| `index.html` | 브라우저로 바로 여는 미리보기(방송 화면 자리 위에 지도가 얹힌 모습) |
| `지도.mp4` | 지도 자리만 담은 영상(좌하단 1/4 이면 960×540) |
| `알파_시퀀스\` | 투명 배경을 골랐을 때. 전체 프레임 1920×1080, 지도 바깥은 투명한 PNG 묶음 |
| `job.json` | 찾은 지점과 후보, 경로 길이, 주의 사항 기록 |

`make` 옵션: `--layout <배치>` 배치만 바꿔 다시 만들기 · `--no-video` 미리보기만 · `--alpha` 투명 배경 시퀀스 · `--offline` 저장해 둔 지도 데이터만 사용.
`serve` 옵션: `--port <번호>` · `--no-open` · `--offline`.

## 의뢰 봉투

의뢰서를 읽은 결과가 이 모양의 JSON 이 된다. 지도 제작은 이것만 본다. 예시는 [examples/홍대_여의도.json](examples/홍대_여의도.json).

| 항목 | 뜻 |
|---|---|
| `from` · `to` | 출발·도착. `{"name": "홍대"}` 처럼 이름만 주면 그 일대의 대표 지점을 쓴다. 정확한 지점이 필요하면 `lat` · `lon` 을 같이 준다 |
| `duration_seconds` | 영상 길이(1~60초) |
| `layout` | `full` 전체 화면 · `bottom_half` 하단 1/2 · `bottom_left_quarter` 좌하단 1/4 · `bottom_right_quarter` 우하단 1/4 |
| `vehicle` | `bus` · `car` · `dot` (코드로 그린 아이콘) |
| `faces` | 얼굴 그림 경로 목록(TGA·PNG·JPG·SVG, 8장까지). 파일이 없으면 번호 동그라미로 대신 그린다 |
| `face_mode` | `above` 이동 아이콘 위에 나란히(기본) · `ride` 버스 창문에 얼굴을 태운다(이동 아이콘이 버스일 때) |
| `map_style` | 지도 형식. `route_move` 경로 이동 지도 · `nav` 네비 지도(같은 그림에 남은 거리 표시가 붙는다). 둘 다 종이·물감·붓펜 재질로 그린다 |
| `output` | 전체 프레임 크기와 초당 프레임. 기본 `{"width": 1920, "height": 1080, "fps": 30}` |
| `program` · `requester` · `text` | 프로그램명 · 의뢰자(이름·역할·전화) · 의뢰 원문 — 기록용 |

이름으로 찾은 지점은 길이 꼬여 도는 구간을 정리하면서 큰길 쪽으로 조금 옮겨질 수 있다(옮긴 거리는 실행 결과에 나온다).
좌표를 직접 준 지점(메신저에서 지도로 정한 지점 포함)은 옮기지 않는다.

## 순위판(표 기반 정보판)

메신저에 표를 붙여 넣거나 줄글로 적으면 순위판 의뢰로 받는다. 지도 의뢰와 같은 길(확인 카드 → 미리보기 → 영상 → 규격 확인)을 탄다.

```
게임 점수 순위판 부탁드립니다. 960*540, 8초.
제목: 오늘의 게임 점수 순위
1위 김가상 1,250점
2위 이가상 1,180점
3위 박가상 965점
```

- 표는 스프레드시트에서 복사한 것(탭), `이름,점수` 같은 쉼표 표, `1위 김가상 98.5점` 같은 줄글을 다 받는다. 이때는 모델을 쓰지 않는다.
- 표가 의뢰서 그림(JPG·PDF) 안에 있으면 Liner 모델이 읽는다. 이때는 글에 '순위판'(또는 순위·랭킹·TOP n)이라고 적혀 있어야 순위판 의뢰로 본다.
- 내용을 지키는 규칙(`mapcg/board.py`):
  - 값은 적은 글자 그대로 화면에 나간다(쉼표·소수점·단위를 고치지 않는다). 숫자로 바꾼 값은 막대 길이와 정렬에만 쓴다.
  - 빈 값은 0 으로 채우지 않고 돌려보낸다.
  - 순위는 적혀 온 것 / 적힌 순서 / 값으로 계산 가운데 무엇을 썼는지 남기고, 값과 어긋나거나 동점이 있으면 '주의'로 알린다.
  - 줄마다 이름표(id)가 붙어, 순서를 바꾸거나 고쳐도 같은 줄을 가리킨다.
- 10줄까지(6줄을 넘으면 두 단으로 나눈다). 지금은 전체 화면 배치만 된다.

명령줄로도 만든다. 의뢰 봉투에 `"kind": "rank_board"` 가 있으면 순위판이다.

```
python -m mapcg make examples\순위판_게임점수.json            # 순위판.mp4
python -m mapcg make examples\순위판_게임점수.json --sheet    # 검수판(자동 검사 결과가 아래에 적힌다)
```

```
  templates/broadcast.js      방송 기본 묶음 — 어느 화풍에서도 지키는 안전 영역 · 같이 싣는 글꼴 · 소품 아이콘 · 가장 작은 글자

```

알아 둘 점

- 처음 보는 구역은 공개 지도 서버에서 받느라 30초쯤 걸릴 수 있다(한 번 받으면 저장해 다시 쓴다).
- PDF 를 그림으로 바꾸는 도구(pdf.js)는 저장소에 넣어 두었다(`mapcg\web\vendor\pdfjs`, 외부에서 받아 실행하지 않는다). 글꼴이 들어 있지 않은 한글 PDF 만 글자 표를 인터넷에서 받는다.
- 작업(읽기·지도 만들기·내보내기)이 도는 동안에는 `새 대화` 가 거절된다 — 끝난 뒤에 누른다.
- Claude 로그인 오류를 한 번 겪으면 앱을 다시 켤 때까지 Claude 를 건너뛴다(왼쪽 띠에 "로그인 필요"로 나온다).
- 간이 해석은 그림을 읽지 못한다. 모델 쪽이 다 안 될 때 의뢰서 그림만 보내면 확인 카드가 빈 채로 온다.
- Claude 는 부를 때마다 `claude` 도구를 한 번 실행한다(그림을 여는 도구 하나만 주고, 파일 접근은 임시 폴더로 묶는다). 사용량은 그 도구에 로그인한 계정에서 나간다.
- 메신저 화면의 굵은 글꼴(Pretendard)은 인터넷에서 받아 온다. 없으면 맑은 고딕으로 보인다.
- V5 화풍의 화면 글자는 저장소에 넣어 둔 글꼴(`mapcg\templates\fonts`, Pretendard 굵은 것 두 개)로 그린다. 작업 폴더에 같이 복사되므로 글꼴이 깔리지 않은 컴퓨터에서도 같은 글자로 나온다. 다른 화풍(V1~V4)은 컴퓨터에 깔린 맑은 고딕을 쓴다(맞춤 그래픽 · 카드 퀴즈는 어느 화풍이든 프리텐다드). 같은 폴더에 새 화풍용 제목 글꼴 셋(Black Han Sans · Do Hyeon · Jua)도 있다 — 모두 SIL OFL 1.1 이고, 사용권 원문 `OFL_*.txt` 와 출처 목록 `글꼴_사용권.md` 를 같이 둔다(글꼴을 더하면 원문도 같이 — 시험이 본다).
- 안전 영역은 프레임 가장자리에서 5% 안쪽으로 잡았다(`style_v5.js` 의 `safe`). 방송사 기준이 더 엄하면 그 숫자만 키운다. 화면을 나눠 쓰는 배치(1/4 등)는 글자도 같은 비율로 작아진다.
- `자산\얼굴\01~04.svg` 는 코드로 그린 가상 출연자다. 같은 번호의 TGA·PNG 를 넣으면 그쪽이 먼저 쓰인다.
- 대화는 `data\messenger\대화.json` 에 남고, `새 대화` 를 누르면 `지난대화\` 로 옮겨진다(지우지 않는다).

## 지도 데이터와 출처 표기

지도 도형과 지명은 OpenStreetMap, 경로는 OSRM 공개 서버에서 키 없이 받는다. 구글 지도는 쓰지 않는다.
지명은 먼저 서울 안(서울시청 둘레 20km)에서 찾고, 의뢰에 장소(공원 · 광장 등)가 적혀 있으면 그 둘레 5km 에서 먼저 찾는다 — '시청' · '시청광장'처럼 여러 도시에 있는 이름이 다른 도시로 잡히지 않는다. 서울에 없는 이름만 전국에서 찾고 그 사실을 알린다(`MAPCG_REGION=all` 이면 처음부터 전국).
결과물을 쓸 때 **© OpenStreetMap contributors** 표기가 필요하다. 경로는 승용차 기준 도로 경로이고 실제 버스 노선이 아니다.

기존 결과물과 새로 만든 부분의 구분은 [기존_신규_구분.md](기존_신규_구분.md).

## Liner 연결 점검

키를 넣은 뒤 한 번 돌려, 이 앱이 쓰는 호출이 실제로 되는지 단계별로 확인한다(아주 짧은 호출 다섯 번).

```
python -m mapcg check                      글 · 지도 틀 · 순위판 틀 · 그림 읽기 · 판독 감사
python -m mapcg check --image 의뢰지.jpg   그 의뢰지를 앱과 같은 길로 실제로 읽혀 본다
```

키는 `.env` 의 `LINER_API_KEY=` 뒤에 사람이 직접 넣는다(`.env` 는 제출물과 저장소에 들어가지 않는다). 점검은 키를 화면에 찍지 않는다.

## 지도 서버가 안 될 때

바탕 지도(도로·강 모양)를 주는 공개 서버는 자주 붐빈다. 그래서 서울은 지도 묶음(`mapcg/packs/`, 2.8MB)을 앱에 넣어 두었다.

- 서울 안의 큰길 지도는 서버를 부르지 않고 묶음으로 그린다.
- 골목길까지 필요한 가까운 화면은 서버에 묻고, 안 되면 묶음의 큰길 지도로 그린 뒤 그 사실을 알린다.
- 서울 밖이고 서버도 안 되면 바탕 없이 경로와 이름표만 그리고 알린다.
- 지명 찾기와 경로 계산은 묶음에 들어 있지 않다. 서버를 둘씩 두고 한쪽이 안 되면 다른 쪽에 묻는다(인터넷은 필요하다).

```
python -m mapcg pack seoul        묶음을 다시 받아 만든다(12조각으로 나눠 천천히 받는다)
```

### 받는 양의 한도

2026-11-20 에 지명이 다른 도시로 잡혀(전주의 '월드컵경기장', 부산의 '월드컵대로') 지도 7개·1.4GB 를 잘못 받은 일이 있었다. 그 뒤로 아래 한도를 둔다(`mapcg/geo.py` 맨 위의 숫자).

| 한도 | 값 | 근거 |
|---|---|---|
| 지도 도형 응답 하나 | 40MB (`MAPCG_MAX_MAP_MB` 로 바꿈) | 정상으로 받은 40개(서울 컷·묶음 조각)의 최대가 5.1MB, 잘못 받은 것은 63~308MB |
| 한 번에 받는 범위 | 큰길만 0.6도² · 골목길까지 0.02도² | 서울 전체가 0.16도², 골목길 화면은 0.005도² 안쪽. 넘으면 서버에 묻지 않는다 |
| 한 의뢰가 지도 서버에 쓰는 몫 | 기다림 120초 · 80MB · 6번 | 정상 응답은 조각 하나에 2~20초. 컷 여러 개와 대체 서버가 이 몫을 같이 쓴다 |
| 쌓아 두는 지도 도형 | 500MB | 넘으면 새로 받은 것은 그리는 데만 쓰고 저장하지 않는다(있던 파일은 지우지 않는다) |
| 컷 나눔의 경로 | 150km, 경유지 하나로 돌아가는 거리 30km | 지점들을 직선으로 이어 본 뒤에 경로 서버에 묻는다. 넘으면 경로·지도를 한 번도 묻지 않고 멈춘다 |

- 한도에 걸리면 받아 둔 지도 → 지도 묶음(큰길만) → 바탕 없는 지도 차례로 대신 그리고, 무엇으로 그렸는지 결과 카드와 작업 기록(`job.json` 의 `map.source`)에 남긴다.
- 응답 200 이어도 서버가 중간에 그만둔 답(`remark` 에 시간 초과)은 정상 지도로 저장하지 않는다.
- 일반 지도(컷 나눔이 아닌 것)의 장거리 의뢰(서울→부산)는 막지 않는다. 범위가 한도보다 넓으면 바탕 지도 없이 경로와 이름표만 그리고 알린다(위도 2도·경도 2.5도를 넘으면 지명이 잘못 잡힌 것으로 보고 멈춘다).
- 한도보다 큰 파일이 `data/geo` 에 있으면 열지 않는다. 앱이 지우지는 않는다 — 정리는 사람이 한다.

## 오프라인으로 켜기

`--offline` 을 주면(`make`·`serve` 둘 다) **키가 있어도 밖으로 아무것도 보내지 않는다** — 지명·경로·지도 도형 서버, Liner 의 읽기·감사·지명 묻기·검색 모두. 저장해 둔 경로는 만들어지고, 처음 보는 경로는 무엇이 없는지 알려 준다. 메신저는 의뢰를 간이 해석으로만 읽는다(그림은 읽지 못한다).

## Liner 호출 기록

보낸 시도 하나가 `data/liner_calls.jsonl` 에 한 줄로 남는다 — 의뢰 번호(`request`), 한 번의 물음(`call`)과 몇 번째 시도인지(`attempt`), 무엇을 물었는지(`task`), 응답 상태, 걸린 시간, 쓴 토큰. 키와 주고받은 글·그림은 적지 않는다(`LINER_LOG=off` 로 끈다).

- 의뢰 번호는 의뢰를 읽을 때 붙고, 확인 카드를 거쳐 제작 때의 호출(지명 묻기·검색)까지 이어진다. `liner.tally("의뢰-…")` 로 의뢰 하나의 읽기·감사·검색 횟수와 토큰을 센다.
- 키·잔액·권한 문제(401·402·403)로 한 번 거절되면 같은 의뢰의 다음 호출은 보내지 않는다.
- 보낸 뒤 답을 기다리다 끊긴 호출은 다시 보내지 않는다(접수됐는지 알 수 없어 두 번 처리될 수 있다) — 기록에 '접수 여부 불명'으로 남는다. 보내지 못한 것(접속 실패)과 429·5xx 는 150초 안에서만 다시 보낸다.

## 화풍 — 바꾸기와 새 화풍(V6) 더하기

화면 틀(배치 · 움직임을 그리는 코드)과 화풍(색 · 선 · 재질 · 바탕판 · 제목판 · 장식)이 나뉘어 있다. 화풍 하나는 `mapcg/templates/style_*.js` 파일 하나다.

- **지금 고르기**: 모든 확인 카드의 '화풍' 단추, 결과 카드의 '다른 화풍으로 다시 만들기'(지도 · 컷 · 순위판 · 정보판 · 카드 퀴즈 · 맞춤 그래픽). 맞춤 그래픽 시안은 같은 장면 설계를 다른 화풍으로 그리기만 한다(Liner 를 부르지 않는다 — 검수 결과는 원래 화풍 시안의 것이라고 카드에 적는다). 네비 화면은 화풍이 없다.
- **방송 화풍(`request.HOUSE_STYLE`, 지금 V5)**: 새 의뢰의 확인 카드가 고른 채로 시작하는 화풍. 화풍을 적지 않은 옛 봉투(명령줄 · 예시)는 예전처럼 V1(`DEFAULT_ART_STYLE`)로 그린다.
- **방송 기본 묶음(`templates/broadcast.js`)**: 안전 영역(가장자리 5%) · 같이 싣는 프리텐다드 · 소품 아이콘 · 가장 작은 글자. 맞춤 그래픽 · 카드 퀴즈 화면과, V1~V5 다음에 더한 새 화풍의 모든 화면에 들어간다(V1~V4 로 그리던 옛 지도 · 순위판은 예전 그대로). 바탕이 어두운 화풍에서는 바탕 위에 바로 놓는 글자 · 빈 칸 점선 · 화살표를 흰색으로 그린다(화풍이 `onBg` 로 정할 수 있다).

**새 화풍(V6) 더하기** — 레퍼런스 그림 3~4장은 `data/화풍_레퍼런스/v6/` 에 둔다(깃 · 제출 묶음 밖 — 남의 그림이다).

1. 레퍼런스를 보고 `mapcg/templates/style_v6.js` 를 쓴다(`style_v5.js` 를 본으로). 정하는 것: 붓의 성질(`Brush.STYLE`) · 순위판 쪽 값(`BOARDSKIN`: 바탕 · 종이 · 먹 · 노랑 · 편 색 · 메달 · 막대 · 제목판 · 마감, `backdrop` 바탕판 · `overlay` 장식) · 지도 쪽 값(`MAPSKIN`: 땅 · 강 · 길 · 녹지 · 이름표). 안전 영역 · 글꼴 · 아이콘은 방송 기본 묶음이 채운다.
2. 등록 두 줄: `request.ART_STYLES["v6"] = "V6 · …"`, `build.STYLE_FILES["v6"] = "style_v6.js"`(딸린 파일이 더 있으면 `build.STYLE_ASSETS`).
3. 통째로 바꾸려면 `request.HOUSE_STYLE = "v6"` 한 줄.

**화풍 파일로 바뀌지 않는 것**(화면 코드 · 다른 그림 쪽 일):

- 구도 · 배치 · 움직임 — 제목 자리, 카드 모양(둥근 종이 판), 배치 11종의 자리, 들어오기 · 나가기, 덮는 전환의 비스듬한 띠. 화면 코드 6개(`route_move` · `rank_board` · `plan_board` · `building_move` · `card_quiz` · `scene`)에 있다.
- 소품 아이콘 그림(`templates/icons/` 시트 두 장) — V5 그림체 그대로. 바꾸려면 시트를 다시 그린다.
- Liner 그림 모델이 그리는 것 — 카드 퀴즈의 카드 그림, 지도의 이동 아이콘 그림, 맞춤 그래픽의 항목 그림. 화풍과 따로 정해진 그림체이고 한 번 그린 것은 보관해 다시 쓴다.
- 네비 화면(`navi.py`, 휴대폰 길안내 모양).
- 이미 만든 결과 — 저절로 다시 그려지지 않는다. 결과 카드의 화풍 단추로 다시 만든다.
- 글꼴 — 프리텐다드가 기본. 다른 글꼴은 글꼴 파일을 같이 실어야 하고 사용권을 먼저 확인한다.
- 우리 그림은 2D 붓 · 물감 · 종이 코드다. 실사 · 3D · 복잡한 일러스트 레퍼런스는 색 · 선 · 재질 쪽만 따라갈 수 있다.

## 맞춤 그래픽 — 처음 보는 그래픽 의뢰를 메인 에이전트가 임시 담당을 꾸려 만든다 (메신저에 연결 · `mapcg/scene.py`)

종류마다 담당 코드를 미리 만들지 않아도, 처음 보는 의뢰를 받은 **메인 에이전트가 의뢰마다 다른 임시 담당(서브 에이전트)을 스스로 정의**하고, 그 담당이 시안을 그려 **스스로 고쳐 합격**한다.

**메신저에서**: 지도 · 순위판 · 정보판 · 카드 퀴즈 어디에도 안 맞는 글 의뢰가 오면(Liner 연결 · 오프라인이 아닐 때) ① 메인이 지시서를 쓰고 담당을 정의한다(Liner 1~2번) → **지시서 카드** ② 사람이 보고 담당을 빼거나 덧붙일 말을 적은 뒤 '이 지시서로 만들기' → 담당들이 일하고 메인이 다시 시키거나 납품 → 담당마다 **시안 카드**(메인이 납품한 것 먼저) ③ 시안 카드에서 영상 · 투명 PNG 시퀀스로 내보낸다. 메인이 지시서를 못 쓰면 예전처럼 '아직 틀이 없습니다' 카드와 가장 가까운 틀을 알린다.
**남은 요청**: 지도 · 정보판으로 읽혔지만 그 틀로 못 그린 요청(예: 러닝 코스 지도의 '페이스 6분/km 문구')이 남으면, 확인 카드를 먼저 낸 뒤 남은 요청만 메인에게 보인다. 메인이 본체 영상 위에 따로 얹을 그래픽(하단 띠 · 큰 글자 판 등, 바탕 투명)으로 만들 담당을 정하면 지시서 카드가 하나 더 나오고, 본체 그림 안에 그려야 하는 것(예: 지도 위 1km마다 거리 표시)은 까닭만 한 줄로 알린다. '한 화면 지도의 지나는 곳'은 컷을 나누면 되므로 넘기지 않는다. 지시서는 작업 폴더(`output/<시각>_맞춤_<종류>/지시서.json`)에 남고, 만들 때마다 그 아래 `제작_<시각>/` 에 담당별 시안이 쌓인다. 붙인 그림은 아직 메인이 읽지 않는다(글로만 지시서를 쓴다).
**자료 찾기**: 의뢰 글에 없는 공개 사실(기록 · 순위 · 수치 — "월드컵 최다 우승국 막대그래프")이 있어야 만들 수 있으면 메인이 `research` 로 Liner 에이전트(Quick Answer)에게 출처가 붙은 답을 받는다(의뢰마다 2번까지).
사실의 근거(quote)는 의뢰 글이나 그 출처의 원문에 있어야 받고(코드가 대조한다), 지시서 카드에 '찾은 자료'(물음 · 답 · 출처 사이트 · 날짜)와 사실마다 출처가 붙는다. 담당은 화면 아래 주석에 '자료: 사이트'를 적고, 검수자도 출처를 보고 판정한다. 찾아도 없으면 '자료 필요'로 알린다.

**명령줄 실험**(지시서부터 납품까지 한 번에, 결과는 `output/에이전트실험/`):

```
python tools/agent_lab.py samples                                   배치 9종 보기 그림(Liner 를 부르지 않는다)
python tools/agent_lab.py run 시험의뢰/에이전트_개발/04_진술대조.txt     의뢰 하나
python tools/agent_lab.py batch 시험의뢰/에이전트_개발                 폴더의 의뢰를 차례로 + 결과표
python tools/agent_lab.py export <시안 폴더> --alpha                    납품 MP4 + 투명 PNG 시퀀스(무거운 일)
```

- **메인**(Liner 도구 호출, `liner-claude-router`): 의뢰 글을 읽고 `write_brief`(제작 지시서: 사실과 원문 근거 · 단정하지 않을 것 · 확인할 점) 뒤에 `spawn_worker`(임시 담당: 역할 · 목표 · 맡을 사실 · 쓸 배치 · 합격 기준 · 시도 한도)나 `report_unable`(기존 담당 · 자료 필요 · 사람 지정 필요 · 새 도구 필요)을 부른다. 미리 정해 둔 담당 목록은 주지 않는다 — 그릴 수 있는 배치(재료) 목록만 준다. 도구 호출을 코드가 검사해(원문에 없는 근거 · 없는 사실 id · 맡은 담당이 없는 사실) 걸리면 한 번 더 묻는다. 담당들이 끝나면 **각 `spawn_worker` 의 도구 결과로 담당의 결과(합격 여부 · 일한 순서 · 미해결)와 마지막 시안 그림이 메인에게 돌아가고**, 메인이 시안을 보고 `redo_worker`(고칠 점을 주어 다시 시킴, 담당마다 한 번)나 `deliver`(납품할 담당 + 제작진에게 보낼 말)를 고른다.
- **담당**(서브 에이전트 — 자기 대화 + 도구): `draw_draft`(장면 설계로 정지 시안 그리기 + 코드 검사 + 자동 검사, 과금 없음) · `request_review`(Liner 그림 읽기 `liner-gpt-router` 로 합격 기준 판정 + 화면 글자 대조) · `submit` · `give_up` 을 **언제 몇 번 부를지 담당이 정한다.** 그린 뒤에는 시안 그림을 담당에게 보여 준다. 코드는 그리기 · 검수 한도만 지키고, 검수를 통과한 마지막 시안을 낸 때만 '합격'으로 센다.
- **모델은 그림 코드를 짜지 않는다.** 장면 설계(배치 이름 · 묶음 · 순서 · 강조)만 쓰고, 자리 · 글자 크기는 `mapcg/templates/scene.html`(순위판과 같은 무대 · 붓 · V5 화풍)이 안전 영역 안에서 정한다. 배치 11종: 줄 목록 · 영수증 · 칸 격자 · 막대 · 시간표 · 나란히 · 둘러앉기 · 대화 · 하단 띠 · 큰 글자 판 · 덮는 전환.
- **움직임 · 오프닝 · 전환**: 장면 설계에 들어오기(fade · pop · slide) · 나가기 · 순서(한꺼번에 / 차례로) · 길이만 고르면, 그리는 코드가 박자(제목 → 항목 → 화살표 → 표시)마다 들어오는 때와 곡선을 정한다. 덮는 전환은 비스듬한 평행 띠가 화면을 덮었다 빠지고(한 점에서 뻗는 무늬는 쓰지 않는다) 바탕이 투명하다. `over_video` 면 바탕 없이 그려 방송 화면 위에 얹는다. 움직이는 시안은 네 순간 검수판(움직임.png)으로 판정하고, 검수자에게 글자 크기 실측(가장 큰 글자 높이 / 화면 세로)을 같이 줘 '크게' 같은 조건을 엄하게 본다. 납품은 `export` — 30fps MP4(3초면 90장)와 투명 PNG 시퀀스를 만들고 장수 · 투명도를 실제로 잰다.
- 결과는 `output/에이전트실험/<시각>_<의뢰>/`(메인.json · wN_담당이름/시안K/시안.png · 기록.json · 결과.md)에 쌓인다. 깃과 제출 묶음에는 들어가지 않는다.
- 겪은 것: Claude 라우터에 엄격 틀(json_schema strict)을 줄 때 칸 이름을 `thinking` 으로 쓰면 내용 거름(content_filter)으로 빈 답이 온다 — `memo` 로 바꾸면 된다. 원문과 견주는 확인할 점은 검수자에게 원문을 같이 줘야 판정된다.

## 연구실 — 앱에 없는 종류의 화면 틀 초안 뽑기 (개발 단계 도구)

앱에 없는 종류의 의뢰(대진표 · 점수 변화 그래프 …)가 왔을 때, Liner 에게 우리 무대 약속과 기존 화면 코드를 본보기로 주고 **새 화면 틀의 초안**을 짜게 한다. 받은 코드는 격리해 그려 보고, 사람이 화면을 보며 고칠 점을 적어 주면 Liner 가 고친다.

```
python tools/lab.py selftest                              격리가 실제로 바깥 접속을 막는지 확인(처음 한 번)
python tools/lab.py new examples/연구실_점수변화그래프.json   1회차: 초안(Liner 1번) → 글자 검사 → 격리해 찍기
python tools/lab.py fix 점수변화그래프 "고칠 점"             다음 회차: 앞 화면을 같이 보여 주고 고치게 한다(Liner 1번)
python tools/lab.py shoot 점수변화그래프                     다시 찍기만
```

- **제작 현장은 그대로다.** 메신저와 명령줄은 지금처럼 모델이 만든 코드를 실행하지 않는다. 연구실에서 나온 틀은 사람이 화면과 코드를 보고, 읽기(설계도 틀) · 검사 · 시험을 붙여 `mapcg/templates` 에 넣기 전에는 어떤 의뢰에도 쓰이지 않는다.
- **격리는 세 겹**: ① 받은 코드의 글자 검사(바깥 접속 · 시계 · 난수 · 이름을 숨기는 수법이 있으면 실행하지 않는다) ② 실행하는 사본에 내용 보안 정책을 넣어 같은 출처 밖으로 못 부르게 ③ 브라우저를 죽은 프록시로 띄워 이 컴퓨터 밖으로 못 나가게. `selftest` 가 ②와 ③을 따로 확인한다.
- 결과는 `output/연구실/<과제>/회차N/`(받은코드.html · 기록.json · 화면_*.png)과 `보기.html` 에 쌓인다. 깃과 제출 묶음에는 들어가지 않는다.
- 2026-11-21 실제 실행: '점수 변화 그래프' 과제에서 1회차(답한 모델 claude-fable-5.2 · 185초 · 282줄)에 우리 화풍의 꺾은선 그래프가 오류 없이 그려졌고, 고칠 점 네 가지를 적은 2회차(claude-sonnet-5.5 · 76초)에 모두 반영됐다. 같은 프레임은 같은 그림이었고 다른 자료(5명 · 6라운드)에서도 깨지지 않았다. 회차당 토큰 3만 남짓.
- 한계: 화면이 방송에 낼 만한지는 사람이 본다(자동 검사는 간격 · 구도를 모른다). 본보기가 판 화면(`plan_board.html`)이라 지도가 얽힌 종류는 아직 못 한다. 정지 화면만 찍는다(움직임은 채택 전에 영상으로 따로 본다). 그림이 든 물음(고치기)은 라우터가 다른 모델로 보낸다.
